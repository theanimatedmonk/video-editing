# video-editing

A Claude Code skill with tested motion recipes for HyperFrames / GSAP video compositions.

Install: clone into `~/.claude/skills/video-editing` (the folder name is the skill name).

| Recipe | File |
|---|---|
| Glide cut — left glide with horizontal motion blur at the cut | `references/glide-cut.md` |
| Glitch exit — RGB-split tear as a headline leaves | `references/glitch-exit.md` |
| Smooth line motion — soft arrival, steady glide, never parked | `references/smooth-line-motion.md` |
| Vector songbirds — shaded birds that bank, flap and chirp | `references/vector-songbirds.md` |
| Number → orbit — pixel-front stat into an orbit of tiles around a badge | `references/number-to-orbit.md` |
| Audio rules — versioned automation, ducking, effects | `references/audio-rules.md` |
| Style notes | `references/style-notes.md` |

Add a recipe: one markdown file in `references/` with the copy-ready code and the numbers that worked, plus a row in `SKILL.md`.
